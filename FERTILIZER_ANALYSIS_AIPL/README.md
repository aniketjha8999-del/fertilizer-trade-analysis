# Global Fertilizer (NPK/NPS) Trade & Tender Data Analysis

Exploratory data analysis of global NPK/NPS fertilizer spot sales, export
shipments, Indian import arrivals, and Indian government tender activity,
built from a weekly fertilizer market report.

## Key questions answered
- How are spot cargo prices trending by destination?
- Which product grades move the most volume and revenue?
- Is Indian import demand seasonal?
- How often do government tenders actually get awarded vs scrapped?
- Does cargo lot size affect price?

## Tech stack
Python, Pandas, NumPy, Matplotlib, Seaborn, openpyxl

## How to run
pip install -r requirements.txt
Open notebooks/NPK_ANALYSIS.ipynb in Jupyter and run all cells.
